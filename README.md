# Game One

Game, where you can run in a forest, collect herbs, shrooms and leafs. Explore Caves and mountains around. Just chill in this survival game

# REQ

* run 
* walk
* sit
* crouch
* attack
* eat
* jump
* Collect Items
* Set up Camp
* Inventory
* Craft Potions
* Start fire in camp
* Sleep

# Technical

* 3d
* Free camera
* Day/Night cycle
* Weather
* Character Switch (?)
* Pause / Settings
* Controller / Keyboard support
* Linux native
